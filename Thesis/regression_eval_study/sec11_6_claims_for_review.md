```
u_1 = F̂_1(y_1)

```

與相應重新標號的預測上，記 `u^(π)`、`z^(π)`；**其第 j 個分量對應次序中的第 j 個位置，不是座標 j**。

等相關矩陣 `Σ_ρ = (1−ρ)I_d + ρ·1 1ᵀ`（對角線恆為 1），**正定範圍 `−1/(d−1) < ρ < 1`**
（特徵值為 `1+(d−1)ρ` 一重、`1−ρ` 的 `d−1` 重）。

## R1 — 定理 11.7（Rosenblatt 變換的 iid 均勻性）

**主張（修訂後）.** 先固定條件 CDF 的一個**聯合可測版本**（正則條件分布；因 `R^d` 為 Polish 空間故存在），使 `u` 確為隨機向量。
若 `Y ~ F̂`（預測正確），且對每個 `j` 與 **`F̂_{1:j-1}`-幾乎每個** `y_{1:j-1}`（即依 `F̂` 之下 `Y_{1:j-1}` 的法則；
`j = 1` 時該元組為空，假設讀作「`F̂_1` 連續」），條件 CDF `F̂_{j|1:j-1}(· | y_{1:j-1})` 皆連續，則
`u_1,…,u_d` 為 iid `U(0,1)`，等價地 `z_1,…,z_d` 為 iid `N(0,1)`。

書中另附兩項限定：
1. **參考測度不可換成 Lebesgue 測度**——存在預測，其條件 CDF 在 Lebesgue-幾乎每點連續、卻在一個 `F̂`-機率為 1 的集合上不連續，結論隨之失效。
   這對本節特別要緊，因為 §11.5–§11.6 的真相與預測都集中在 Lebesgue 零測集上。
2. **引用與敘述分離**：Rosenblatt (1952, 印刷頁 470–472) `doi:10.1214/aoms/1177729394` 對**絕對連續**的 `F̂` 證明了此變換；
   書中敘述只要求各條件 CDF 連續，**嚴格更弱**（純奇異的預測，例如 Cantor 型法則，滿足假設而沒有密度），而證明逐字不變。

**證明（對 d 歸納）.**
`d = 1` 即定理 4.1。設結論對 `d−1` 成立；**歸納假設施加在邊際 `F̂_{1:d-1}` 上**——它的條件 CDF 正是 `j ≤ d−1` 的那些
`F̂_{j|1:j-1}`，而在預測正確之下它也正確預測 `Y_{1:d-1}`。給定 `Y_{1:d-1} = y_{1:d-1}`：由假設
`F̂_{d|1:d-1}(· | y_{1:d-1})` 是連續 CDF，而 `Y_d` 的條件法則正是該 CDF，故由定理 4.1 得
`u_d | Y_{1:d-1} = y_{1:d-1} ~ U(0,1)`。關鍵在於這個條件法則對 **`F̂`-幾乎每個** `y_{1:d-1}` 都等於**同一個** `U(0,1)`，
因此作為正則條件分布它**幾乎必然**等於 `U(0,1)`：於是 `u_d` 與 `Y_{1:d-1}` 獨立、且 `u_d ~ U(0,1)`。
又 `u_{1:d-1}` 是 `Y_{1:d-1}` 的可測函數，故 `u_d` 與 `u_{1:d-1}` 也獨立；配合歸納假設即得結論。

**書中的紙筆檢查點（修訂後）.** 「這個證明**沒有**用到 `F̂` 有密度，也沒有對 `F̂` 的各座標假設任何獨立性；
除此之外它只用了『條件法則正確』、『條件 CDF 連續』，以及上述聯合可測版本的存在。」

**數值旁證.** `d = 4`、`Σ_{0.6}`、從**該預測本身**抽 3×10⁵ 個樣本、再做 Rosenblatt：
逐座標 `mean(u) ∈ [0.4969, 0.5013]`（目標 0.5）、`var(u) ∈ [0.0824, 0.0854]`（目標 `1/12 = 0.083333`）、
`max |off-diag corr(z)| = 0.00428`。

**已知軟點 / 請特別檢查.**
1. **連續性夠不夠？** 主張只假設每個條件 CDF **連續**，沒有假設絕對連續。純量 PIT 在僅連續之下確實成立；請確認條件版本的每一步都只需要連續性。
2. **`F̂`-a.e. 的反例是否真的存在？** 審查者給的構造：`d = 3`，`Y_1 ~ N(0,1)`，`Y_2 | Y_1 ~` Cantor 法則（條件 CDF 對每個 `y_1` 皆連續），
   `Y_3 | (y_1,y_2)` 在 `y_2 ∈ Cantor 集` 時為 `y_2` 處的點質量、否則為 `N(0,1)`。不連續集 `R × C` 的 Lebesgue 測度為 0
   但 `F̂`-機率為 1，模擬給 `P(u_3 = 1) = 1.000000`。**請獨立核對這個反例**（書中只敘述了結論，沒有印出構造）。
3. **正則條件分布那一句是否足夠？** 書中只說「固定一個聯合可測版本（正則條件分布，因 `R^d` 為 Polish 故存在）」。請判斷這對嚴格化是否夠，或還需要更多。
4. **引用是否對得上。** 請確認 Rosenblatt (1952) 確實是對絕對連續分布敘述的（審查者稱該文開篇即宣告其對象為絕對連續的 k 元分布），
   且該文為印刷頁 470–472 的短文。**書中原先寫的「§2」已刪除**，因為無法確認該三頁短文有編號小節。

## R2 — 連續性假設不可略去（§11.5 的理想預測恰好違反它）

**主張（修訂後）.** §11.5 的理想預測 `B`（`R²` 上 `(Z, Z)` 的法則，兩分量以機率 1 相等）不滿足定理 11.7 的**連續性**假設：
`Y_2` 在 `Y_1 = y_1` 之下的**條件法則**是 `y_1` 處的點質量，故 `F̂_{2|1}(t | y_1) = 1{t ≥ y_1}` **本身就是**階梯函數。
代入真相 `Y = (Z, Z)`：
```
u_2 = F̂_{2|1}(Y_2 | Y_1) = 1{Z ≥ Z} = 1     幾乎必然
```
書中另附三項限定：
1. **慣例**：此處採右連續慣例 `F̂(t | y_1) = P(Y_2 ≤ t | y_1)`；左極限慣例給 `u_2 = 0`，同樣退化。
   把跳躍隨機化的「隨機化 PIT」確實能還原均勻性，但那是與定義 11.6 **不同的變換**。
2. **失效範圍**：`u_1 = Φ(Z)` 仍精確均勻，失效只發生在 `j ≥ 2`；而且 `z_2 = Φ^{-1}(1) = +∞`，
   即定義 11.6 的殘差在 `R^d` 中**根本不存在**——這才是 `B` 不能用的直接理由（引理 11.8–11.11 全部以 `z` 敘述）。
3. **改用的路徑**：等相關族 `Σ_ρ` 限定在**正定範圍** `−1/(d−1) < ρ < 1`。這條路徑**起**於預測 `A`（`ρ = 0`），
   只在 `ρ → 1` 時*趨近*理想預測而**永遠不含它**；且連續性在**兩端都失效**——`ρ = 1` 處如上，
   `ρ = −1/(d−1)` 處組合變異數歸零、最後一個條件法則同樣塌成點質量。
   至於定理 11.7 的**另一半**假設（預測正確），在這條路徑上**每一點都不成立**，那正是引理 11.9 的全部內容；
   `B` 反而是這裡唯一滿足它的預測。

**數值旁證.** 10⁵ 次模擬：`P(u_2 = 1) = 1.000000`。`d = 4`、`ρ = −1/3 + 10^{-6}`（正定下界附近）：`c_4 = 1154.7`、`Σ c_j² = 1.333×10⁶`。

**已知軟點 / 請特別檢查.**
1. 這裡 `B` **同時是預測也是真相**（它是理想預測）。失效的原因純粹是**預測**的條件 CDF 不連續，與「預測是否正確」無關。請確認書中沒有混淆兩者。
2. 書中說 `ρ → 1` 只是**參數上**的趋近。審查者指出更強的事實：`N(0, 1 1ᵀ)` 與每一個 `N(0, Σ_ρ)`（`ρ<1`）**互相奇異**
   （它給 Lebesgue 零測直線 `y_1 = … = y_d` 機率 1），故全變差距離沿整條路徑恆為 1、KL 為 `+∞`。
   **書中只寫了「永遠不含它」，沒有印出這個奇異性論證** —— 請判斷是否值得補。

## R3 — 引理 11.8（高斯預測下 = 反 Cholesky；以及 `‖z‖²` 的次序不變性）

**主張.** 設 `F̂ = N(0, Σ)`、`Σ` **正定**，取下三角 Cholesky 分解 `Σ = L Lᵀ`（`L_jj > 0`）。則對**每一個** `y ∈ R^d`，
```
z = L^{-1} y                                                       …(11.11)
```
又對任一座標排序 `π`（置換矩陣 `P_π`，約定 `(P_π y)_j = y_{π(j)}`），
```
‖z^(π)‖² = yᵀ Σ^{-1} y      對每一個 π 相同                          …(11.12)
```

**證明（修訂後）.**
**(11.11)**：寫 `X = L ε`，`ε` 分量 iid `N(0,1)`；則 `X ~ N(0, Σ)`，且由 `L` 下三角得 `X_j = Σ_{i≤j} L_ji ε_i`，故
`ε_j = (X_j − Σ_{i<j} L_ji ε_i)/L_jj`。由三角結構，`ε_{1:j-1}` 是 `X_{1:j-1}` 的可逆線性函數，故
`m_j := Σ_{i<j} L_ji ε_i` 是 `X_{1:j-1}` 的線性函數；又 `ε_j ~ N(0,1)` 與 `X_{1:j-1}` 獨立。
於是 `X_j` 在 `X_{1:j-1}` 之下的條件法則**恰為** `N(m_j, L_jj²)`，因此
`u_j = F̂_{j|1:j-1}(y_j | y_{1:j-1}) = Φ((y_j − m_j)/L_jj)`，取 `Φ^{-1}` 得 `z_j = (y_j − m_j)/L_jj = ε_j`。
書中在此加了三句限定：
- 讓 `Φ^{-1}` 能抵銷條件 CDF 的，是條件法則的**高斯性**，不只是它的前兩階矩；
- 此處也正是 **`L_jj > 0` 這個正規化**被用到的地方——它使 `L_jj` 而非 `−L_jj` 成為條件標準差，帶符號的三角因子只能讓 (11.11) 成立到逐座標變號為止；
- 因 `m_j` 是 `y_{1:j-1}` 的顯式線性函數、條件標準差是常數 `L_jj`，此恆等式對**每一個** `y` 成立，不只是 `F̂`-幾乎必然。

**(11.12)**：把 (11.11) 施加在預測 `N(0, P_π Σ P_πᵀ)`（仍為正定）上得 `z^(π) = L_π^{-1} P_π y`，其中 `P_π Σ P_πᵀ = L_π L_πᵀ`。於是
`‖z^(π)‖² = yᵀ P_πᵀ (L_π L_πᵀ)^{-1} P_π y = yᵀ P_πᵀ (P_π Σ P_πᵀ)^{-1} P_π y = yᵀ Σ^{-1} y`，最後一步用 `P_π^{-1} = P_πᵀ`。
與 (11.11) 不同，**(11.12) 只透過 `L_π L_πᵀ` 用到 `L_π`，故對符號慣例完全不敏感**。

**數值旁證.**
- `max |條件矩鏈 − L^{-1} y| = 3.375×10^{-14}`（200 組隨機 `(d, ρ, y)`，`d ∈ [2,6]`）。
- `‖z^(π)‖²` 對**所有**排列的最大偏差 `= 8.882×10^{-16}`（80 組隨機正定 `Σ`，`d ∈ [2,5]`，窮舉全部 `d!` 個排列）。
- 符號慣例確實承重：`d = 5` 取 `L̃ = L·diag(1,−1,1,−1,1)`（仍下三角、仍 `L̃L̃ᵀ = Σ`）則
  `max |L̃^{-1}y − z|` **不為零**（隨 `y` 與 `Σ` 而定，量級 0.1–10），而 `‖L̃^{-1}y‖² − yᵀΣ^{-1}y` 仍在機器精度（`~10^{-16}`）。
  也就是：(11.11) 需要符號慣例，(11.12) 不需要。

**已知軟點 / 請特別檢查.**
1. **`ε_j = z_j` 那一步的高斯性環節（已補）**。初稿只寫「即 `ε_j` 就是標準化的條件殘差 `z_j`」，未說明 `Φ^{-1}` 為何能抵銷條件 CDF。
   審查者指出這一步有實質內容：同樣條件均值 0.4、同樣條件標準差 1.3 的 **Laplace** 條件法則，標準化殘差是 1.307692 而 `Φ^{-1}(u) = 1.414080`。**已修**。
2. `Σ` 僅半正定時 `L^{-1}`、`Σ^{-1}` 皆不存在，(11.11)(11.12) 失效。請確認「`Σ` 正定」的限定沒有在後續被悄悄放寬。
3. **(11.12) 是高斯專屬的**——見 R7 軟點 2。請確認正文沒有把它當成 Rosenblatt 化約的一般性質。

## R4 — 引理 11.9（等相關預測對共單調真相的 Rosenblatt 殘差）

**主張.** 設 **`d ≥ 2`**。真相 `Y = Z·1`（共單調），預測 `N(0, Σ_ρ)`，`−1/(d−1) < ρ < 1`。則
```
z_j = c_j · Z ,      c_1 = 1 ,
c_j = sqrt( (1−ρ) / [ (1+(j−2)ρ)(1+(j−1)ρ) ] )        j ≥ 2
Σ_{j=1}^{d} c_j² = 1ᵀ Σ_ρ^{-1} 1 = d / (1+(d−1)ρ)                 …(11.13)
```
特別地，`c_j = 1` 對一切 `j` 成立**若且唯若** `ρ = 0`。

**證明.** 由引理 11.8（R3），`z = L^{-1} Y = Z · L^{-1} 1`，故 `c = L^{-1} 1`，與 `Z` 的實現值無關。
等相關族的條件矩（由分塊反矩陣）：給定 `k = j−1 ≥ 1` 個已知座標，
```
E[X_j | X_{1:k}]   = ρ/(1+(k−1)ρ) · Σ_{i≤k} X_i
Var(X_j | X_{1:k}) = 1 − kρ²/(1+(k−1)ρ) = (1−ρ)(1+kρ)/(1+(k−1)ρ)
```
（因式分解展開即得 `(1−ρ)(1+kρ) = 1+(k−1)ρ−kρ²`；在所述 `ρ` 範圍上 `1+(k−1)ρ ≥ 1−(k−1)/(d−1) > 0`，故**無奇異點**）。
代入 `X_i = Z` 得條件均值 `kρZ/(1+(k−1)ρ)`，故分子為 `Z(1−ρ)/(1+(k−1)ρ)`；除以條件標準差即得 `c_j`。
平方和用裂項（`ρ ≠ 0` 時）`(1−ρ)/[(1+(k−1)ρ)(1+kρ)] = ((1−ρ)/ρ)[1/(1+(k−1)ρ) − 1/(1+kρ)]`，
對 `k = 1,…,d−1` 相加得 `(1−ρ)(d−1)/(1+(d−1)ρ)`，加 `c_1² = 1` 得 `d/(1+(d−1)ρ)`；`ρ = 0` 時各項皆為 1，直接得 `d`。
`1ᵀΣ_ρ^{-1}1` 亦等於此值，因 `Σ_ρ 1 = (1+(d−1)ρ)·1`。最後 `c_2 = sqrt((1−ρ)/(1+ρ)) = 1` 只在 `ρ = 0` 成立
——**這一步需要 `d ≥ 2`**（`d = 1` 時 `Σ_ρ = [1]` 恆等，`ρ` 不可識別）。

**書中據此下的敘述（重點段，修訂後——請一併審查）.**
取 `ρ = 0`（即預測 `A`）：`c_j = 1` 對一切 `j`，於是每一個 `z_j` 精確 `N(0,1)`、每一個 `u_j` 精確 `U(0,1)`。
**再設真相提供時間上 iid 的重複** `Y^(t) = Z_t·1`，則把 §4 的 PIT 直方圖、可靠度圖、ECE，以及 §10 的 Berkowitz 檢定
**逐座標**施加在 Rosenblatt 輸出上，讀數仍然全綠——與引理 11.2 完全一樣。
（**時間上 iid 是承重假設**：Berkowitz 還讀一個序列相關項，`Z_t` 若有序列相依會被抓到，但那是另一種誤設。）
真正失效的是**跨座標的獨立性**，而且它對這一族的**每一個** `ρ` 都失效，不只 `ρ = 0`：由 `z_j = c_j Z` 且每個 `c_j > 0`，
`corr(z_i, z_j) = 1`（`i ≠ j`），且對任意 `n ≥ 2` 組重複，樣本相關矩陣**恰為全一矩陣、秩為 1**。

限定詞的位置：
- `ρ = 0` 是這一族裡**唯一**讓 **Rosenblatt 殘差尺度**正確（`c_j = 1` 對一切 `j`）的參數值；
- 因 `z_j = c_j Z` 是高斯的，「`u_j` 精確均勻」與「`Var(z_j) = 1`」**是同一個**條件 `c_j = 1`，不是兩個獨立的確認；
- 而**普通的**邊際 PIT `F̂_j(y_j)` 對這一族的**每一個** `ρ` 都精確均勻（`Σ_ρ` 對角線恆為 1），
  所以**逐座標的邊際校準在整族上都是盲的**；
- `ρ ≠ 0` 時 `c_2 ≠ 1`，Berkowitz 的變異數項就看得見了。

結論：Rosenblatt 變換的貢獻不是「**逐座標讀數**抓到了」，而是「把多元校準化約成一個已知的純量虛無假設」——`z` 是不是 iid `N(0,1)`。
該虛無假設有**幾個**可分離的方向（各座標自身的邊際、跨座標的相關、跨時間的序列相關，**以及整體的 `Σ_j z_j²`**），
而 §11.5 的反例**在逐座標的邊際那一項上完全沒有痕跡**。這與 §9.2 把 Christoffersen 檢定拆成無條件覆蓋與獨立性是同一個結構。

## R5 — 引理 11.10（次序相依：`d!` 個變換）

**主張（修訂後）.** `d` 個座標有 `d!` 種排序，每一種給出一個 Rosenblatt 變換；
**只要該次序的條件 CDF 滿足定理 11.7 的連續性假設**，該次序在預測正確時就給出 iid `U(0,1)^d`。
（非退化高斯預測之下每個次序都滿足；但**連續性假設本身是依次序而定的**，一般而言可能對 `(1,2)` 成立而對 `(2,1)` 失效。）
在預測誤設之下這些變換的法則一般不同。取 `d = 3`、真相共單調 `Y = Z·1`、預測為 AR(1) 相關矩陣 `Σ_ij = φ^{|i−j|}`（`0 < φ < 1`）。
則 `z^(π) = Z·c^(π)` 且
```
c^(1,2,3) = ( 1, sqrt((1−φ)/(1+φ)), sqrt((1−φ)/(1+φ)) )
c^(1,3,2) = ( 1, sqrt((1−φ²)/(1+φ²)), (1−φ)^{3/2}/sqrt((1+φ²)(1+φ)) )
```
兩者不同（**依定義 11.6 的約定，`c^(1,3,2)` 的第二個分量屬於 `X_3`、第三個屬於 `X_2`**）；
而由 (11.12)，兩者的 `Σ_j c_j²` 都等於 `1ᵀΣ^{-1}1 = (3−φ)/(1+φ)`。
6 個排序實際上只給出**兩個**不同的 `c`：把 `X_2` 排在最後的兩個排序給出後者，其餘四個給出前者。

**證明.** AR(1) 是 Markov 的，故排序 `(1,2,3)` 下 `X_2|X_1 ~ N(φX_1, 1−φ²)`、`X_3|X_1,X_2 ~ N(φX_2, 1−φ²)`；
代入 `X_i = Z` 得兩個相同的係數 `(1−φ)/sqrt(1−φ²) = sqrt((1−φ)/(1+φ))`。
排序 `(1,3,2)`：先由 `corr(X_1,X_3) = φ²` 得 `X_3|X_1 ~ N(φ²X_1, 1−φ⁴)`，係數 `sqrt((1−φ²)/(1+φ²))`；
再對 `X_2|X_1,X_3`，由 AR(1) 的對稱性得條件均值 `φ(X_1+X_3)/(1+φ²)`、條件變異數 `(1−φ²)/(1+φ²)`，代入 `X_1 = X_3 = Z` 得
```
[1 − 2φ/(1+φ²)] / sqrt((1−φ²)/(1+φ²))
  = [(1−φ)²/(1+φ²)] / sqrt((1−φ²)/(1+φ²))
  = (1−φ)^{3/2} / sqrt((1+φ²)(1+φ))
```
平方和：AR(1) 的逆為三對角，`(1−φ²)Σ^{-1}` 的三個**行和**依序為 `1−φ`、`(1−φ)²`、`1−φ`，合計 `(1−φ)(3−φ)`；
除以 `1−φ² = (1−φ)(1+φ)` 得 `(3−φ)/(1+φ)`，與 (11.12) 一致（`Σ^{-1}` 對稱，故行和與列和相同）。

**數排序（修訂後的完整論證）.** **在 `d = 3` 且對角線為 1 的情形**，`c` 只依賴「哪一個座標排在最後」：
`c_1 = 1` 恆成立；一個排序的前兩個位置恰是最後那個座標的補集，而
`c_2 = sqrt((1−Σ_{π(1)π(2)})/(1+Σ_{π(1)π(2)}))` 與 `c_3`（對其餘兩者同時條件化）都對該配對對稱。
因此至多有**三個**不同的 `c`，一個對應一種「最後座標」的選擇。
而 `{最後 = 1}` 與 `{最後 = 3}` 這兩類**重合**，是因為 AR(1) 矩陣在反轉 `i ↦ 4−i` 之下不變、該反轉把一類映成另一類；
於是只剩兩個不同的 `c`，四個排序給前者、兩個給後者。
**兩個限定都不能拿掉**：
- **反轉對稱性是必要的**：對 Markov 型 `Σ_12 = a`、`Σ_23 = b`、`Σ_13 = ab` 且 `a ≠ b`（例如 `(a,b) = (0.6,0.2)`），
  三類**彼此不同**：`(1, 0.5, 0.8164966)`、`(1, 0.8864053, 0.3618734)`、`(1, 0.8164966, 0.5)`；`a = b` 時才塌成兩個。
- **`d ≥ 4` 時「哪一個排在最後」不再決定 `c`**：AR(1) 在 `d = 4` 的 24 個排序上就有**五**個不同的 `c`。

## R6 — 引理 11.11（Cauchy–Schwarz：組合比值與殘差尺度）

**主張（修訂後）.** 真相 `Y = Z·1`，預測 `N(0, Σ)`，其中 **`Σ` 為正定「相關」矩陣**（對角線為 1，故每個邊際都精確正確，如引理 11.2），
但不必等相關。令 `r = sqrt(1ᵀΣ1)/d`（§11.5.2 式 (11.5) 的組合 VaR 比值 = 模型 ÷ 真實）、`S = 1ᵀΣ^{-1}1`。則
```
(1ᵀΣ1)(1ᵀΣ^{-1}1) ≥ d²         等價地        r ≥ 1/sqrt(S)                 …(11.14)
```
等號成立**若且唯若** `1` 是 `Σ` 的特徵向量，亦即 **`Σ` 的各行和相同**。更強地，對**任一**權重 `w` 且 `wᵀ1 ≠ 0`，
```
r_w := sqrt(wᵀΣw) / |wᵀ1|  ≥  1/sqrt(S) ,   等號成立若且唯若 w ∝ Σ^{-1}1        …(11.15)
```
此外 **`r < 1` 嚴格成立**：在此類別內組合 VaR 一定被低估。

**證明.**
先確認 `S` 就是殘差尺度的平方和：由引理 11.8，`z = L^{-1}Y = Z·c` 其中 `c = L^{-1}1`，故
`Σ_j c_j² = 1ᵀ(LLᵀ)^{-1}1 = 1ᵀΣ^{-1}1 = S`，而由 (11.12) 此值不依賴座標次序。
**(11.14)**：令 `a = Σ^{1/2}1`、`b = Σ^{-1/2}1`。則 `1ᵀΣ1 = ‖a‖²`、`S = ‖b‖²`、`aᵀb = d`。
Cauchy–Schwarz 給 `d² = (aᵀb)² ≤ ‖a‖²‖b‖²`，等號成立若且唯若 `a, b` **線性相依**；
由 `aᵀb = d > 0`，該比例常數**必為** `λ = d/‖b‖² > 0`，而 `Σ^{1/2}1 = λΣ^{-1/2}1` 左乘 `Σ^{1/2}` 等價於 `Σ1 = λ1`。
**反之**，`Σ1 = λ1` 給 `Σ^{-1}1 = λ^{-1}1`，乘積為 `(λd)(d/λ) = d²`。
**(11.15)**：`r_w` 對 `w` 的縮放不變，故可正規化 `wᵀ1 = 1`；此時 `min{wᵀΣw : wᵀ1 = 1} = 1/S`，
於 `w = Σ^{-1}1/S` 達到（Lagrange 條件 `Σw ∝ 1`），故 `r_w² ≥ 1/S`。取 `w = 1/d` 即回到 (11.14)。
**`r < 1`**：令 `v = 1/sqrt(d)`，則 `1ᵀΣ1 = d·vᵀΣv ≤ d·λ_max`；又由 `tr Σ = d` 與 `λ_min > 0` 得
`λ_max ≤ d − (d−1)λ_min < d`。故 `r² ≤ λ_max/d < 1`。

**書中據此下的敘述（修訂後）.**
(11.14) **不是等價關係**，是**單邊不等式**：組合低估與殘差尺度和只有在等號情形（各行和相同）才攜帶同一份資訊；一般而言它們是兩個不同的數字。
因 `1ᵀΣ1 = d + Σ_{i≠j} ρ_ij` 只依賴成對相關的**總和**，`r` 在一整族 `Σ` 上不變而 `S` 可以差一倍以上。
等號的類別也比等相關族大得多：**任何各行和相同的 `Σ`** 都成立。
(11.15) 才是真正有用的敘述：`1/sqrt(S)` 是**所有**投資組合的組合 VaR 比值的下界，由**最小變異數組合** `w ∝ Σ^{-1}1` 達到
——這時「不必先指定權重」才是被證明過的話。
方向也要記對：**`S` 大**（殘差爆開）對應低估**嚴重**，`S` 小（殘差被壓扁）對應低估輕微。

## R7 — `Σ_j z_j²` 不是盲的（§11.6.4 表格之後的段落）

**主張（修訂時新增）.** 在 R4 的設定下取 `ρ = 0`（預測 `A`），由 (11.13) 有 `c_j ≡ 1`，故
```
Σ_{j=1}^{d} z_j² = (Σ_j c_j²) Z² = d·Z²
E[Σ_j z_j²] = d          （恰好正確——與 χ²_d 的均值相同）
Var[Σ_j z_j²] = 2d²      （而非 χ²_d 的 2d）
```
均值恰好正確，離散度卻差了 `d` 倍。把 `Σ_j z_j²` 當 `χ²_d` 做**雙尾**適合度檢定，在名目水準 `2%` 之下，
**單一觀測**的拒絕率就是 `34.2%`（`d = 5`）與 `51.5%`（`d = 10`），樣本一長檢定力就趨於 1。

所以正確的敘述是：`Σ_j z_j²` **看得見**這個誤設；它看不見的是**次序**，也無法把失效**定位到某個座標**；
而能定位的逐座標讀數在此又是全綠的（R4）。

**證明.** `z_j = c_j Z = Z` 對一切 `j`（`ρ = 0`），故 `Σ_j z_j² = d Z²`。`Z² ~ χ²_1` 故
`E = d·1 = d`、`Var = d²·Var(χ²_1) = d²·2 = 2d²`。而 `χ²_d` 的均值 `d`、變異數 `2d`。

**數值旁證.** 4×10⁵ 次模擬：`d = 2` 均值 1.9992、變異數 7.937（`2d² = 8`）；`d = 5` 均值 5.0143、變異數 50.025（`2d² = 50`）；
`d = 10` 均值 10.0188、變異數 201.220（`2d² = 200`）。

```python
def equicorr(d, r): return (1-r)*np.eye(d) + r*np.ones((d, d))

def coeffs(S, order):
    P = np.eye(len(order))[list(order)]

def cond_chain(S, y):
    """z_j from the explicit conditional-mean / conditional-sd chain (Definition 11.6)."""
    d = len(y); z = np.zeros(d)
    for j in range(d):
        if j == 0: m, v = 0.0, S[0, 0]
        else:
            w = np.linalg.solve(S[:j, :j], S[:j, j])
            m = float(w @ y[:j]); v = float(S[j, j] - S[:j, j] @ w)
        z[j] = (y[j] - m) / math.sqrt(v)
    return z

# ---- R7: sum_j z_j^2 = d Z^2 -- correct mean d, variance 2d^2 not 2d ----
def gammainc_lower_reg(s, x):
    if x <= 0: return 0.0
    if x < s+1:
        tot = term = 1.0/s
        for k in range(1, 5000):
            term *= x/(s+k); tot += term
            if abs(term) < 1e-18*abs(tot): break
        return tot*math.exp(-x + s*math.log(x) - math.lgamma(s))
    tiny = 1e-300; b0 = x+1-s; C = 1/tiny; Dd = 1/b0; h = Dd
    for i in range(1, 5000):
        an = -i*(i-s); b = x+2*i+1-s
        Dd = an*Dd+b
        if abs(Dd) < tiny: Dd = tiny
        C = b+an/C
        if abs(C) < tiny: C = tiny
        Dd = 1/Dd; dl = Dd*C; h *= dl
        if abs(dl-1) < 1e-16: break
    return 1.0-math.exp(-x + s*math.log(x) - math.lgamma(s))*h
chi2cdf = lambda x, d: gammainc_lower_reg(d/2.0, x/2.0)
def chi2ppf(p, d):

    for _ in range(300):
        m = (lo+hi)/2
        if chi2cdf(m, d) < p: lo = m
        else: hi = m
```
