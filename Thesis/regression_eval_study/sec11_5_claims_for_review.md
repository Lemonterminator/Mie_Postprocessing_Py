## 7. 池化問題：你的警告方向正確，但還可說得更精確

假設設定 S 中

[
Y_{t,1}=Y_{t,2}=Z_t.
]

令

[
H_{t,j}
=\mathbf 1{|Y_{t,j}|\leq1},
\qquad
p=2\Phi(1)-1.
]

則

[
H_{t,1}=H_{t,2}
]

幾乎必然成立。池化後的總命中數是

[
S_n
=\sum_{t=1}^n(H_{t,1}+H_{t,2})
=2\sum_{t=1}^nH_{t,1}.
]

所以

[
\operatorname{Var}(S_n)
=4np(1-p).
]

若錯誤地把這 (2n) 個命中指標當作 iid Bernoulli((p))，則會使用

[
\operatorname{Var}_{\mathrm{iid}}(S_n)
=2np(1-p),
]

恰好將方差低估一半。也就是說，池化並沒有產生 (2n) 個獨立資訊，實際有效樣本量仍接近 (n)。

但需要補上一個非常重要的細節：

> 因為 (A) 與 (B) 的邊際 CDF 完全相同，池化後的 PIT 或命中指標在同一資料集上，於 (A) 和 (B) 之間仍然完全相同。

因此池化檢定仍然不能有效區分 (A) 和 (B)。它可能發生的是：

1. 池化後違反 iid 虛無參考分布；
2. 標準誤被低估；
3. 檢定可能過度拒絕；
4. 甚至可能連正確的聯合模型 (B=P) 也一起拒絕。

所以問題不是「池化後突然能辨識 (A)」，而是「池化後使用了一個錯誤的獨立性參考分布」。

你目前的軟點可以改成：

> 本主張首先針對每個固定分量 (j) 的診斷。若將不同分量池化為單一序列，則同一觀測個體內的 PIT 或命中指標可能相關，因而通常不再服從標準檢定所假設的 iid Uniform 或 iid Bernoulli 虛無分布。這會改變計數統計量的方差並可能導致尺寸失真。不過，由於 (A) 與 (B) 的邊際預測完全相同，池化後的邊際診斷值在兩模型之間仍相同；此類池化檢定並不能有效辨識聯合分布錯設。

\Phi^{-1}(1/2)=0.
]

所以严格表述应当是：

[
\frac{\operatorname{VaR}^{\mathrm{pred}}*\alpha}
{\operatorname{VaR}^{\mathrm{true}}*\alpha}
===========================================

\frac1{\sqrt d},
\qquad
\alpha\in(0,1)\setminus\left{\frac12\right}.
]

或者更简洁地避免比值，直接写缩放恒等式：

[
\operatorname{VaR}^{\mathrm{pred}}_\alpha
=========================================

d^{-1/2}\operatorname{VaR}^{\mathrm{true}}_\alpha,
\qquad 0<\alpha<1.
]

在通常风险管理语境中，若本来就限定 (0<\alpha<1/2)，这个例外自然不会出现。

### 3. ES 的结论正确，但最好直接写出定义

若在收益尺度上定义下尾风险值为

[
\operatorname{ES}_\alpha(X)
===========================

-\frac1\alpha\int_0^\alpha q_u(X),du,
]

那么对于 (X\sim N(0,\sigma^2))，

[
\operatorname{ES}_\alpha(X)
===========================

\sigma\frac{\phi(z_\alpha)}{\alpha}.
]

因此

[
\operatorname{ES}^{\mathrm{true}}_\alpha
========================================

d\frac{\phi(z_\alpha)}{\alpha},
\qquad
\operatorname{ES}^{\mathrm{pred}}_\alpha
========================================

\sqrt d\frac{\phi(z_\alpha)}{\alpha},
]

从而

[
\frac{\operatorname{ES}^{\mathrm{pred}}*\alpha}
{\operatorname{ES}^{\mathrm{true}}*\alpha}
==========================================

\frac1{\sqrt d},
\qquad 0<\alpha<1.
]

这里 ES 的分母不会在 (\alpha=\tfrac12) 消失，所以 ES 比值对整个 ((0,1)) 都有定义。

正齐次性也成立：

[
\operatorname{ES}_\alpha(cX)
============================

c,\operatorname{ES}_\alpha(X),
\qquad c>0.
]

事实上，“收益尺度”不是正齐次性成立的必要条件。无论采用尾部收益均值，还是在前面加负号后作为正的风险量，只要符号定义一致，对 (c>0) 都正齐次。真正需要特别检查的是：书中使用的 FZ0 公式究竟把输入写成

[
(q_\alpha,\operatorname{ES}_\alpha)
]

还是写成

[
(-q_\alpha,-\operatorname{ES}_\alpha).
]

不能只改变 VaR 的符号而不相应变换 ES 和评分函数。

### 4. “FZ0 完全无法补救”这一句过强

这是目前最重要的实质性问题。

如果只对每个分量 (Y_j) 分别进行边际评估，那么 FZ0 或其他严格一致评分确实看不到依赖结构错误。所有边际都是正确的 (N(0,1))，所以边际诊断存在盲区。

但如果直接对聚合量

[
S_d=\sum_jY_j
]

的预测 VaR 和 ES 使用 FZ0 评分，那么 FZ0 在总体上**能够检测出这个错误**。

设

[
T(F)=\bigl(\operatorname{VaR}*\alpha(F),
\operatorname{ES}*\alpha(F)\bigr).
]

严格一致性意味着，在真实分布 (F_{\mathrm{true}}) 下，

[
\mathbb E_{F_{\mathrm{true}}}
S!\left(T(F_{\mathrm{true}}),S_d\right)
<
\mathbb E_{F_{\mathrm{true}}}
S!\left(T(F_{\mathrm{pred}}),S_d\right),
]

只要两对功能值不同且满足相应正则条件。这里

[
T!\left(N(0,d^2)\right)
\neq
T!\left(N(0,d)\right),
]

所以错误的聚合 VaR–ES 对会受到更差的期望评分。

因此，更准确的推论应是：

> ((\operatorname{VaR},\operatorname{ES})) 的联合可引出性不能验证或恢复完整的联合分布，也不能消除仅做边际评估时的依赖结构盲区。不同联合分布可能具有相同边际，甚至可能具有相同的某一组 VaR–ES 功能值。
> 但是，一旦直接对聚合量 (S_d) 的 VaR–ES 预测进行 FZ0 评分，严格一致性原则上能够检测此例中的错误聚合风险预测；它不能告诉我们错误来自相关性，也不能恢复正确的联合机制。

所以应当区分三个层次：

[
\text{边际 FZ/其他评分}
\quad\Rightarrow\quad
\text{看不到依赖错误};
]

[
\text{对 }S_d\text{ 的 FZ0 评分}
\quad\Rightarrow\quad
\text{能够发现 VaR–ES 对错误};
]

[
\text{对 }S_d\text{ 的 FZ0 评分}
\quad\nRightarrow\quad
\text{识别或验证完整联合分布}.
]

最终建议是：保留分布推导和 (1/\sqrt d) 放大倍数；把 VaR 比值的定义域排除 (\alpha=1/2)；并将“FZ0 完全无法补救”改成“FZ0 无法验证联合依赖结构，但直接用于聚合风险时可以检测错误的 VaR–ES 对”。

  （用 `P(|Z| ≤ a) = erf(a/√2)`）。
- **小 r**：`erf(r/2) = r/√π + O(r³)` 為一階，`1 − e^{−r²/2} = r²/2 + O(r⁴)` 為二階，故 `C_P > C_A`。
- **大 r**：比較兩個補值。由 `erfc(x) ~ e^{−x²}/(x√π)` 得 `erfc(r/2) ~ 2e^{−r²/4}/(r√π)`；
  而 `e^{−r²/4} / e^{−r²/2} = e^{r²/4} → ∞`，故對充分大的 `r` 有 `erfc(r/2) > e^{−r²/2}`，即 `C_P < C_A`。
- 兩函數連續、兩端異號，中間值定理給出 `r*` 存在。

**本書據此下的敘述.** 一次只在單一層級上做的聯合覆蓋率稽核，若恰落在 `0.7848451`，**在結構上不可能拒絕 `A`**。
落差**不單調**：同一個錯誤預測在中段過度覆蓋、在尾部覆蓋不足。並附帶：1σ 這一列的名目值 `0.393469 = P(χ²₂ ≤ 1) = 1 − e^{−1/2}`，
不是第一部的 `0.6826895 = P(χ²₁ ≤ 1)`；「1σ 覆蓋 68.3%」是純粹的**一維**事實。

**已知軟點 / 請特別檢查.**
1. **本引理只證存在性，唯一性是數值結論**，本書明文如此寫。唯一性在 `r ∈ (0, 200]` 上以取對數的方式驗證：
   比較 `ln erfc(r/2)` 與 `−r²/2`（直接相減會有相消誤差——`r ≳ 11.6` 時兩個覆蓋率在雙精度下都等於 1，
   naive 掃描會在 `r ≈ 11.66` 報出一個**假的**第二個根。這個陷阱已在證明中註明）。
2. 「1σ 球」在此指 `{‖z‖ ≤ 1}`，即 `A` 的 Mahalanobis 半徑 1（因 `Σ_A = I₂`）；不是任何邊際的 ±1σ 區間。請確認用語沒有混淆。

## C9 — 兩個紙筆檢查點

**C9a（在 §11.5.1）.** 把設定 S 的 `A` 換成任何相關係數 `ρ` 的二維**標準**高斯 `N(0, [[1,ρ],[ρ,1]])`，C1（引理 11.2）照樣成立，
因為共變異數矩陣的**對角線與 `ρ` 無關**。故一整族錯誤的預測共用同一組邊際讀數。

**C9b（在 §11.5.3）.** 同樣把 `A` 換成相關係數 `ρ` 的二維標準高斯。則 `X₁ − X₂ ~ N(0, 2 − 2ρ)`，故

```
E|X₁ − X₂| = √(2/π)·√(2 − 2ρ) = 2√((1−ρ)/π)
VS₁(A, y)  = (0 − 2√((1−ρ)/π))² = 4(1 − ρ)/π
```

在 `ρ = 0` 還原 `4/π`（C5），在 `ρ = 1` 歸零。故變異圖分數量的是**相依性缺口本身**。

**已知軟點.** C9b 用了 `E|N(0,σ²)| = σ√(2/π)`，此處 `σ = √(2 − 2ρ)`；請確認 `ρ = 1` 的退化情形（`σ = 0`）處理正確。

## C11 — 互動實驗 15 的閉式（等相關族的推廣）

**記號.** 真實機制同 C2：`Y_j ≡ Z`（`j = 1,…,d`，`Z ~ N(0,1)`，共單調）。
預測改為**等相關**高斯 `F_ρ = N(0, Σ_ρ)`，`Σ_ρ = (1−ρ)I_d + ρ𝟙𝟙ᵀ`（對角線恆為 1）。
`ρ = 0` 時 `F_ρ` 就是 C1–C8 的預測 `A`；`ρ = 1` 時 `F_ρ` 就是理想預測 `B`。

**主張.**

```
(a) 正定性：Σ_ρ 的特徵值為 1+(d−1)ρ（一重，特徵向量 𝟙）與 1−ρ（d−1 重）。
    故 Σ_ρ 正定 ⟺ −1/(d−1) < ρ < 1 ；ρ = 1 時退化為秩 1。
(b) 邊際不變：對每個 ρ 與每個 d，F_ρ 的第 j 個邊際皆為 N(0,1)。
    ⟹ C1（引理 11.2）逐字成立，與 ρ、d 無關。
(c) 變異圖分數（p=1，每一對）：VS₁(F_ρ, y) = 4(1−ρ)/π ，對每個 y ∈ supp P 成立。
    全部 C(d,2) 對以權重 1 加總：C(d,2)·4(1−ρ)/π。
(d) 組合泛函 S_d = Σ_j Y_j：Var_{F_ρ}(S_d) = 𝟙ᵀΣ_ρ𝟙 = d(1+(d−1)ρ)，
    而真實機制的 Var(S_d) = d²。故對每個層級 α，
        VaR_α(F_ρ) / VaR_α(真實) = ES_α(F_ρ) / ES_α(真實) = √((1+(d−1)ρ)/d)。
    ρ = 0 還原 C2 的 1/√d；ρ = 1 給 1；ρ = −1/(d−1) 給 0（組合變異數恰為零）。
(e) 「兩個部位同日皆為負」：Sheppard 象限公式給出
        P_{F_ρ}(X_i < 0, X_j < 0) = ¼ + arcsin(ρ)/(2π) ，
    而真實機制為 P(Z < 0) = ½。ρ=0 → ¼、ρ=1 → ½、ρ=−1 → 0。
```

**證明.**

- **(a)** `Σ_ρ𝟙 = (1−ρ)𝟙 + ρd𝟙 = (1+(d−1)ρ)𝟙`；任一與 `𝟙` 正交的 `v` 滿足 `Σ_ρv = (1−ρ)v`。
- **(b)** `Σ_ρ` 的對角線元素為 `(1−ρ) + ρ = 1`，與 `ρ` 無關。
- **(c)** `X_i − X_j ~ N(0, 2−2ρ)`，故 `E|X_i − X_j| = √(2/π)·√(2−2ρ) = 2√((1−ρ)/π)`；
  真實機制下 `|Y_i − Y_j| = 0` 幾乎必然，故 `VS₁ = (0 − 2√((1−ρ)/π))² = 4(1−ρ)/π`。
- **(d)** `𝟙ᵀΣ_ρ𝟙 = d + d(d−1)ρ`。兩邊皆零均值高斯，`VaR_α = −σΦ^{-1}(α)`，比值中 `Φ^{-1}(α)` 相消。
- **(e)** Sheppard：二維標準高斯相關係數 `ρ` 時 `P(X>0, Y>0) = ¼ + arcsin(ρ)/(2π)`；由對稱性同式適用於 `P(X<0, Y<0)`。

**數值（已與 4×10⁵ 次 Monte Carlo 逐格核對，全部相符）.**

**已知軟點 / 請特別檢查.**
1. (d) 的比值與 `α` 無關，倚賴**兩邊都恰好是高斯**（真實機制 `S_d = dZ` 精確高斯）。不是近似。
2. `ρ = 1` 時 `Σ_ρ` 奇異，`F_ρ` 退化在 `𝟙` 方向的一維子空間上；(c)(d)(e) 在該處**仍然良定**（都只用到二階矩或二維邊際），但任何需要 `Σ_ρ^{-1}` 的量（例如 Mahalanobis 區域）在該處不存在。實驗 15 **刻意不顯示** Mahalanobis 讀數，正是為了避免這個邊界。
3. 實驗 15 右圖畫的是**任兩個分量的二維邊際**。等相關使該二維邊際對每個 `d` 都恰是 `(1,ρ)` 的二維標準高斯——這是精確敘述，不是 `d=2` 的示意圖。
4. (e) 的 Sheppard 公式常被寫成 `P(X>0,Y>0)`；本書用的是 `P(X<0,Y<0)`，兩者由 `(X,Y) ↦ (−X,−Y)` 的對稱性相等。請確認沒有符號錯位。

## 附錄：數值重算腳本

所有常數可由下列自包含腳本重算（只需 `numpy`；本機 `scipy` 的編譯擴充被應用程式控制政策封鎖，**不要**依賴 `scipy.stats`）。

```python
import numpy as np, math
Phi = lambda x: 0.5*(1+math.erf(x/math.sqrt(2)))
S2P, SP = math.sqrt(2/math.pi), math.sqrt(math.pi)

# C1
print('1/sqrt(pi)   ', 1/SP)                       # 0.5641895835
print('(1+ln2pi)/2  ', (1+math.log(2*math.pi))/2)  # 1.4189385332
print('2Phi(1)-1    ', 2*Phi(1)-1)                 # 0.6826894921
print('sqrt(2/pi)   ', S2P)                        # 0.7978845608

# C2
for d in (2,5,10,50,252): print(f'd={d:>4} 1/sqrt(d)={1/math.sqrt(d):.6f} under={100*(1-1/math.sqrt(d)):.2f}%')

# C3, C4 : angular constant I = int_0^{pi/2} sqrt(1+2cos^2 t) dt = sqrt(3)*E(2/3)
n = 400000; t = (np.arange(n)+0.5)*(math.pi/2)/n
I = float(np.sum(np.sqrt(1+2*np.cos(t)**2)))*(math.pi/2)/n
print('sqrt3*E(2/3) ', I)                          # 2.1844381427
print('E(2/3)       ', I/math.sqrt(3))             # 1.2611859497
EW = S2P*I;            print('E||X-Y||     ', EW)  # 1.7429294681
SA = EW - SP/2;        print('S(A)         ', SA)  # 0.8567025427
SB = S2P;              print('S(B)         ', SB)  # 0.7978845608
print('gap          ', SA-SB, f'({(SA-SB)/SB*100:.4f}%)')   # 0.0588179819 (7.3717%)

# C5
print('4/pi         ', 4/math.pi)                  # 1.2732395447
for d in (2,10,50): print(f'  C({d},2)*4/pi = {math.comb(d,2)*4/math.pi:.4f}')

# C6 : m(lam) = E||X-y||, X~N(0,I2), ||y||=lam, by polar quadrature centred at y
NR, NT = 1500, 800
def m_rice(lam):
    rmax = lam+45.0
    r  = (np.arange(NR)+0.5)*rmax/NR;   dr  = rmax/NR
    th = (np.arange(NT)+0.5)*math.pi/NT; dth = math.pi/NT
    R, T = r[:,None], th[None,:]
    return float(np.sum(R**2*np.exp(-(lam**2+2*R*lam*np.cos(T)+R**2)/2)))*dr*dth/math.pi
assert abs(m_rice(0.0) - math.sqrt(math.pi/2)) < 1e-9        # sanity: 1.2533141373
def D(z):
    a = m_rice(math.sqrt(2)*abs(z)) - SP/2
    b = math.sqrt(2)*(2*math.exp(-z*z/2)/math.sqrt(2*math.pi) + z*(2*Phi(z)-1)) - S2P
    return a - b
x, w = np.polynomial.hermite.hermgauss(60); x = x*math.sqrt(2); w = w/SP
Dv = np.array([D(float(v)) for v in x]); mD = float(np.sum(w*Dv))
sD = math.sqrt(float(np.sum(w*Dv**2)) - mD**2)
print('E[D], sd[D]  ', mD, sD)                     # 0.05881798, 0.01670151  (E[D] must match the gap above)
lo, hi = 1.45, 6.0
for _ in range(60):
    mid = (lo+hi)/2
    lo, hi = (mid, hi) if D(mid) > 0 else (lo, mid)
zc = (lo+hi)/2
print('z_c, P(|Z|>z_c)', zc, 2*(1-Phi(zc)))        # 4.033615, 5.493e-05

# C7 : coverage. compare in LOGS to avoid cancellation (a naive scan invents a root near r=11.66)
def logerfc(x):
    return math.log(math.erfc(x)) if x < 25 else -x*x - math.log(x*SP) + math.log1p(-1/(2*x*x))
psi = lambda r: logerfc(r/2) + r*r/2               # >0 <=> under-coverage
lo, hi = 1.0, 3.0
for _ in range(200):
    mid = (lo+hi)/2
    lo, hi = (mid, hi) if psi(mid) < 0 else (lo, mid)
rc = (lo+hi)/2
print('r*, level    ', rc, math.erf(rc/2), 1-math.exp(-rc*rc/2))   # 1.75293874, 0.78484511
for r in (1.0, rc, 2.4477468, 3.0348542):
    print(f'  r={r:.6f} nominal={1-math.exp(-r*r/2):.6f} actual={math.erf(r/2):.6f}')

# C8
q = 0.02792
print('single, true, indep (萬元):', q*1e8/1e4, 10*q*1e8/1e4, math.sqrt(10)*q*1e8/1e4)
```
